SERVICE ÁNGEL — Sitio web para GitHub Pages

ESTRUCTURA
- index.html: página principal.
- assets/css/styles.css: estilos y diseño adaptable.
- assets/js/main.js: menú, preguntas frecuentes y formulario de WhatsApp.
- assets/img/logo-service-angel.png: logotipo con fondo transparente.
- assets/img/emprendedores-inventario.jpg: ilustración principal.

SUBIR A GITHUB
1. Crea un repositorio público, por ejemplo: service-angel.
2. Descomprime este paquete.
3. Sube el contenido de la carpeta service_angel_github al nivel principal del repositorio.
   IMPORTANTE: index.html debe quedar en la raíz, no dentro de otra carpeta.
4. En GitHub abre Settings > Pages.
5. En Build and deployment selecciona Deploy from a branch.
6. Selecciona la rama main y la carpeta /(root), guarda.
7. Espera a que GitHub Pages publique el sitio.
